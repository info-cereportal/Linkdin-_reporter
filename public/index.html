                METHODOLOGY · 編集方針

                記事はどのように選ばれているのか

                • 取得 arXiv q-bio.NC RSS と PubMed E-utilities から 直近24–72時間のエントリを取得。3時間ごとに自動更新。
                • 選定 重複排除 + キーワード重み付け (脳情報・神経AI・神経画像 等) で 本日の1本を選出。
                • 編集 6種のナラティブテンプレート (paradigm-shift / data-driven / three-insights / future-vision / neuro-ai-bridge / provocative-question) を年内日次でローテーション。
                • Hedging 医学的断定 / 再現性 / 誇張 / 引用欠落 をパターン検出し、 risk_score > 30 で表現を自動緩和。
                • 公開 GitHub Actions が public/data/*.json をコミット → Firebase Hosting にデプロイ。

                本サイトの記事は研究情報のメタ紹介を目的としています。 医療上の判断・治療方針については必ず専門医にご相談ください。
